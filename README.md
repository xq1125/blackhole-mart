# 黑洞便利店 · Black Hole Mart

一家开在宇宙尽头的便利店，24 小时营业，只收好奇心。

投一枚好奇心，随机带走一件平行宇宙好物；也可以自己写一件离谱商品，上架到店里赚钱。官方图鉴已经从 43 件扩到 **88 件**，仓库本身不设上限——抽到的住客投稿也会一起收进去。

![黑洞便利店预览](preview.png)

**在线玩：** <https://xq1125.github.io/blackhole-mart/>

## 怎么玩

- **拉摇杆 / 按「拉一下 · 补货」/ 按空格**，随机抽取一件好物。
- 每次抽签消耗 **8.8 宇宙币**；余额不够时，店长请客，本次免费。
- 抽到的好物自动进入 **「我的黑洞仓库」**。
- **图鉴**是 88 件官方好物（85 件常规 + 3 件隐藏款），仓库里还可能有住客投稿，所以仓库数量可以超过图鉴。
- 「今日到货」由日期决定，每天打开会换一件。

## 怎么赚宇宙币

- **每日签到**：共创货架里的「今日签到 +30」，每天一次。
- **写一件好物**：上架稿费 = `max(30, 20 + 售价 × 0.6)` 币，售价越高，稿费越高。
- **拿销售分成**：商品上架后会立刻卖出第 1 件，作者拿售价的 30%；之后每次有顾客买走，也会继续分成。
- **重复款寄售**：抽到已经拥有的好物时，会自动寄售，换回售价的 50%。
- 抽签、重复款、销售和签到都会实时更新右上角的宇宙币余额。

## 共创货架

- 写商品时可以填：名称、售价、图标、卖点、分类、副作用、署名。
- 投稿通过后立刻上架，并获得稿费和首位顾客分成。
- 自己的作品会出现在「共创货架」最前面，标着 **我的作品**；卡片上会显示已售数量和每件分成。
- 页面自带 8 件「其他住客」的投稿作为初始货架，让店里看起来有人气。

> **关于“大家”：** 这是纯静态的 GitHub Pages 版本，投稿和余额都保存在当前浏览器的 localStorage 里，不会同步给其他访客；初始的“其他住客”是内置的虚构投稿。如果要做真正跨设备的多人共创，需要接一个后端（例如 Supabase 或 Firebase）。页面上的「本地共创版」标注的就是这个限制。

## 运行

零依赖、零构建，纯静态页面。

直接双击 `index.html` 就能玩。

想获得更完整的剪贴板体验，建议用本地服务器打开：

```powershell
cd blackhole-mart
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 一些实现细节

- 纯 HTML / CSS / JS，无图片资源，无第三方字体和依赖，离线可用。
- 售货机、黑洞、猫店长、贴纸和印章都是 CSS 画的；商品图标使用系统 emoji。
- 小票的条形码由商品 id 和日期生成，带一点确定性随机。
- 音效用 Web Audio API 实时合成，不加载音频文件。
- 收藏、余额、签到、投稿和音效偏好存在 `blackhole-mart.v1` 这个 localStorage key 里。
- 响应式覆盖到 320px 宽；手机端的共创货架是横向滑动的卡片流。
- 支持键盘操作、`prefers-reduced-motion`，复制和投稿窗口使用原生 `<dialog>`。

## 想改点什么

- 官方商品库：编辑 `app.js` 顶部的 `PRODUCTS` 和 `RARE_PRODUCTS`。
- 初始住客投稿：编辑 `COMMUNITY_SEEDS`。
- 抽签价格、签到奖励、分成比例：搜索 `DRAW_COST`、`CHECKIN_BONUS`、`ROYALTY_RATE`、`DUPLICATE_RATE`。
- 隐藏款概率：搜索 `RARE_CHANCE`。
- 主色、纸张色、字体：编辑 `styles.css` 顶部的 CSS 变量。
