# 黑洞便利店 · Black Hole Mart

一家开在宇宙尽头的便利店，24 小时营业，只收好奇心。

投一枚好奇心，随机带走一件平行宇宙好物：会同时出现在被窝和工位的量子拖鞋、把老板声音变成背景音的情绪气泡水、只在你不想起床时有效的时间暂停按钮……还有 3 件很少露面的隐藏款。

![黑洞便利店预览](preview.png)

## 怎么玩

- **拉摇杆 / 按「拉一下 · 补货」/ 按空格**，随机抽取一件好物。
- 每次抽到的东西会自动进入**「我的黑洞仓库」**，关掉页面也会保留（localStorage）。
- 点击机器上的**猫店长**，可以摸摸它，听听它想说什么。
- **「复制这张小票」**会把商品信息整理成一段文字；浏览器不给剪贴板权限时，会打开一个手动复制窗口。
- 右上角可以开关**音效**。
- 「今日到货」由日期决定，每天打开会换一件。
- 常规好物 40 件 + 隐藏款 3 件，共 43 件。隐藏款概率约 7.5%。

## 运行

零依赖、零构建，纯静态页面。

直接双击 `index.html` 就能玩。

如果想获得更完整的剪贴板体验，建议用本地服务器打开：

```powershell
cd blackhole-mart
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 一些实现细节

- 纯 HTML / CSS / JS，无图片资源，无第三方字体和依赖，离线可用。
- 售货机、黑洞、猫店长、贴纸和印章都是 CSS 画的；商品图标使用系统 emoji。
- 小票的条形码由商品 id 和日期生成，带一点确定性随机。
- 音效用 Web Audio API 实时合成，不加载音频文件。
- 收藏和音效偏好存在 `blackhole-mart.v1` 这个 localStorage key 里；「清空仓库」可以重置收藏。
- 响应式覆盖到 320px 宽；支持键盘操作、`prefers-reduced-motion`，复制窗口使用原生 `<dialog>`。

## 想改点什么

- 商品库：编辑 `app.js` 顶部的 `PRODUCTS` 和 `RARE_PRODUCTS`。
- 隐藏款概率：搜索 `RARE_CHANCE`。
- 主色、纸张色、字体：编辑 `styles.css` 顶部的 CSS 变量。
- 文案和页面结构：编辑 `index.html` 里对应的文本。
